# آپاراتچی موبایل

اپ مستقل فیلم و سریال با React Native و Expo؛ اندروید در اولویت است و ساختار پروژه برای iOS هم آماده مانده است.

## وضعیت نسخه ۰٫۱۱

- رابط فارسی و راست‌چین مخصوص موبایل
- مدیریت قطع اینترنت برای پخش و دانلود با پیام فارسی و تلاش دوباره
- دسته‌بندی کودکان، مذهبی و برنامه‌ها و مسابقه‌ها
- بارگذاری مرحله‌ای صفحه خانه و منوی پایین سازگار با Safe Area اندروید
- بازشدن روان‌تر پوستر، جزئیات، ستارگان و کنترل‌ها با عقب‌انداختن پردازش‌های سنگین تا پایان تعامل کاربر
- کش شرطی کاتالوگ با `ETag` و `Last-Modified`؛ فایل چندمگابایتیِ بدون تغییر دوباره پردازش نمی‌شود
- صفحه خانه سینمایی، جست‌وجو، نشان‌شده‌ها و صفحه جزئیات
- جدول هفتگی جداگانه ایرانی و خارجی
- برنامه ایرانی از فایل JSON قابل‌به‌روزرسانی
- بررسی محدود، هم‌زمانی کنترل‌شده و کش‌شده قسمت بعدی سریال‌های خارجی با TVmaze
- پشتیبانی از پخش و دانلود ویژه اینترنت همراه و لینک کوتاه معتبر `redl.ink`
- دریافت فهرست فیلم‌ها، برنامه ایرانی، لینک پخش و لینک دانلود از یک فایل JSON روی GitHub
- بازشدن لینک پخش یا دانلود ثبت‌شده با ابزار مناسب دستگاه
- بازگشت خودکار به اطلاعات داخلی اپ اگر فایل آنلاین در دسترس نباشد
- خروجی APK آزمایشی با GitHub Actions یا EAS

## بدون سایت، هاست و دامنه چطور کار می‌کند؟

خود اپ به سایت نیاز ندارد. فایل `content/catalog.json` را می‌توانید در یک مخزن GitHub قرار دهید و آدرس Raw آن را در `src/config.ts` وارد کنید. با ویرایش همان فایل، فهرست و لینک‌ها بدون انتشار APK تازه به‌روزرسانی می‌شوند.

نکته: GitHub فقط کد و فایل JSON را نگه می‌دارد. فایل ویدئو یا لینک پخش باید روی یک سرویس مجازِ جداگانه قرار داشته باشد؛ فایل فیلم نمی‌تواند بدون هیچ فضای ذخیره‌سازی آنلاین ارائه شود.

## اتصال فایل محتوا به GitHub

1. پروژه را در یک مخزن GitHub قرار دهید.
2. فایل `content/catalog.json` را نگه دارید و اطلاعاتش را ویرایش کنید.
3. در GitHub فایل را باز کنید و روی **Raw** بزنید.
4. آدرس Raw را در `src/config.ts` جایگزین مقدار خالی `REMOTE_CONTENT_URL` کنید.

نمونه آدرس:

```text
https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/content/catalog.json
```

در فایل نمونه، لینک‌های `example.com` فقط برای نمایش ساختار هستند و باید با لینک‌های قانونی خودتان جایگزین شوند.

## ساختار لینک‌ها

هر عنوان می‌تواند `streamUrl` و چند گروه دانلود داشته باشد:

```json
{
  "streamUrl": "https://example.com/video.m3u8",
  "downloads": [
    {
      "id": "dubbed",
      "title": "نسخه دوبله فارسی",
      "subtitle": "کیفیت‌های هماهنگ‌شده",
      "badge": "FA",
      "files": [
        {
          "id": "dubbed-720",
          "quality": "۷۲۰p",
          "label": "مناسب موبایل",
          "size": "۸۵۰ مگابایت",
          "url": "https://example.com/video-720.mp4"
        }
      ]
    }
  ]
}
```

## اجرای پروژه

```bash
npm ci
npm run start
```

## ساخت APK آزمایشی

با EAS:

```bash
eas build --platform android --profile preview
```

یا پروژه را روی شاخه `main` در GitHub قرار دهید؛ گردش‌کار `.github/workflows/android-apk.yml` پس از `npm ci` و تایپ‌چک، APK نسخه Release را می‌سازد.
